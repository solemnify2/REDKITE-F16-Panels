# TWA 패널 PCB — LED 추가 개조

Greenisland 의 TWA 패널 기판(`Schaltplan TWA v35`)에 **Power 계열 LED 3개와 그 구동 회로를
추가**한 개조입니다. 본 프로젝트에서 쓰는 기판은 이 개조를 적용한 `v36` 입니다.

> **개조 파일 자체는 배포하지 않습니다.** 상류 설계가 바탕인 2차적저작물이라, 인클로저와
> 같은 이유로 저장소에 싣지 않습니다 ([LICENSE](../../LICENSE) NOTICE).
> 이 문서는 **무엇을 어떻게 바꿨는지**만 적습니다. 원본은 Cults3D 에서 구매해 받으시고,
> 아래 내용을 본인 파일에 직접 적용하십시오.

---

## 1. 바뀐 것

| | 원본 v35 | 개조 v36 |
|---|---|---|
| LED | 4 (버튼당 1개) | **7** |
| 220Ω | 4 | **7** |
| MOSFET | 없음 | **AO3400A 1개** |
| 10kΩ | 1 (래더 풀다운) | **2** (게이트 풀다운 추가) |

래더(2.2kΩ ×4 + 10kΩ), 택트 스위치 4개, `J1` 1×7 커넥터, 필터 커패시터는 **건드리지
않았습니다.** 기존 LED 4개와 그 220Ω 도 그대로입니다.

**추가 부품**

| 지정 | 값 | 풋프린트 |
|------|-----|----------|
| D5 · D6 · D7 | 녹색 3mm LED | `LED_THT:LED_D3.0mm` |
| R11 · R12 · R13 | 220Ω | `R_1210_3225Metric` |
| R10 | 10kΩ | `R_1206_3216Metric` |
| Q1 | AO3400A (N-ch) | `SOT-23` |

---

## 2. 왜

실기의 SYS PWR 쪽은 표시등이 하나로 끝나지 않습니다. 원본은 버튼마다 LED 1개라
Power 자리도 1개뿐이어서, **4개로 늘리려면 구동 방식을 바꿔야 합니다.**

LED 4개를 한 신호핀에서 직접 당기면 핀 전류가 그만큼 늘어납니다. 그래서 기존 1개만
핀에서 구동하고, **추가한 3개는 `VCC` 에서 전류를 받아 MOSFET 으로 스위칭**합니다.
신호핀은 게이트만 흔들므로 전류가 늘지 않습니다.

---

## 3. 추가 회로

`LED_SYS` (= `J1` 6번, Teensy 핀 34) 하나가 두 가지를 합니다.

```
  LED_SYS ──┬── R7 220Ω ── D4 ── GND          기존 — 핀이 직접 구동
            │
            ├── R10 10kΩ ── GND               게이트 풀다운 (추가)
            │
            └── Q1.G
                 AO3400A   G=1  S=2  D=3
                 Q1.S ── GND
                 Q1.D ── LED_G_K
                            │
     VCC ── R11 220Ω ── D5 ─┤                 추가 3개는 VCC 에서 급전
     VCC ── R12 220Ω ── D6 ─┤
     VCC ── R13 220Ω ── D7 ─┘
```

- `LED_SYS` 가 HIGH → Q1 도통 → `LED_G_K` 가 GND 로 당겨져 D5·D6·D7 점등
- `R10` 은 핀이 입력 상태(리셋·부팅 중)일 때 게이트가 뜨지 않게 잡아 줍니다. **빠뜨리면
  전원 투입 시 Power LED 가 멋대로 켜집니다.**
- D4 는 원본 그대로 `LED_SYS` → `R7` → GND 경로입니다. 개조 후에도 4개가 같이 켜집니다.

나머지 3개 채널(`LED_ACT` · `LED_SEARCH` · `LED_LOWALT`)은 원본과 동일하게 핀 직결입니다.

---

## 4. 적용

1. Cults3D 에서 Greenisland TWA 패널을 구매해 `Schaltplan TWA v35` 를 받습니다.
2. KiCad 로 열어 위 4종 부품을 추가하고 3항의 네트대로 연결합니다.
3. D5·D6·D7 은 패널 Power 표시창 위치에 맞춰 배치합니다 — 좌표는
   `Top Layer` STL 과 레이저 커팅 DXF 에서 실측하십시오.
4. DRC 를 돌리고 거버를 뽑아 발주합니다.

`VCC` 는 **3.3V 입니다.** 기판 실크에 `5V` 라고 찍혀 있어도 Teensy 3.3V 를 넣으십시오 —
이유는 [REF_LEFT_AUX_WIRING.md](../REF_LEFT_AUX_WIRING.md) 의 「다른 래더와의 차이」 절.
